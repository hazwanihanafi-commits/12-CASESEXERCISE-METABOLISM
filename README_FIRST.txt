TCE504 Exercise Metabolism – Combined 12-case interactive website

1. Extract the ZIP. Keep index.html and case-01.html through case-12.html in the SAME folder.
2. Open index.html in a browser or upload all files to the root of a GitHub Pages repository.
3. Each case retains its own simulator, quiz and reflection. Local browser storage depends on browser/device.
4. A feedback box is included below the case dashboard. Clicking Submit saves feedback in THAT STUDENT’S browser only. Students can download the feedback JSON and share it with their lecturer. It is not a centralized submission.
5. To collect feedback automatically from all students, a Google Form or Apps Script feedback collection endpoint must be configured. Do not claim records are sent to Google Sheets until tested.
